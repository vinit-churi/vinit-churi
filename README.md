### 🛠 What I'm building

| Project | What it is | Status |
|---|---|---|
| **[ReelForge](https://reelforge.studio)** | Turns a talking-head video into a post-ready reel: auto subtitles from word-timed transcripts, sentence-level editing on a timeline, stock B-roll and music, background rendering. Accounts, free and paid tiers, Razorpay billing. Built with [@Duo-Bytes](https://github.com/Duo-Bytes). | 🟢 **Live in production** · private |
| **[TraceSarkar](https://github.com/vinit-churi/tracesarkar)** | Civic accountability for the Mumbai Metropolitan Region: photograph a civic problem, get back the responsible authority, the contract that was paid to prevent it, and the escalation route. | 🟡 Early build · **public** |
| **ViharSync** | Management platform for small co-operative housing societies in Maharashtra: dues, maintenance requests, notices, polls, documents, accounts. Web console, mobile app, landing site. | 🟡 In development · private |

<details>
<summary><b>How ReelForge is put together</b></summary>

<br>

- **Frontend:** Next.js + React + Tailwind, deployed to Cloudflare Workers
- **Backend:** FastAPI on Python, MongoDB (Beanie/Motor), Celery + Redis for render jobs, ffmpeg
- **Cloud:** Google Cloud Storage and Speech-to-Text, Docker Compose
- **Product analytics:** PostHog funnels from upload → transcript → editor → export, and billing page → payment

</details>
